# DAC-3D 缺陷判定指南

## 1. 判定原则

DAC-3D 的缺陷判定不是简单地“检测到框即不合格”。系统先由本地模型检测候选缺陷，再根据样品圆形区域、缺陷尺寸、缺陷类别和工艺规则确定是否合格。

当前系统中的有效缺陷类别包括：

- `splash`
- `scratch`
- `chipping`

最终结果中，`is_qualified=False` 且 `is_ignored=False` 的缺陷会影响样品合格性。

## 2. 区域含义

系统把样品圆面划分为 A/B/C/D/OUT 五类区域：

- A：中心区域。
- B：中内圈区域。
- C：中外圈区域。
- D：边缘区域。
- OUT：样品圆外或无效区域。

区域来自 `region_ratio`：

| 区域 | 范围 |
| --- | --- |
| A | `0 <= ratio < 0.333` |
| B | `0.333 <= ratio < 0.519` |
| C | `0.519 <= ratio < 0.815` |
| D | `0.815 <= ratio <= 1.0` |
| OUT | 其他 |

## 3. 规则解释

### A 区

A 区靠近样品中心，规则相对严格。小尺寸 `splash`、短而窄的 `scratch` 可被允许；超过阈值或数量阈值后会判为不合格。

### B 区

B 区允许少量中小尺寸 `splash`，但大尺寸 `splash` 和超限 `scratch` 会触发不合格。B 区划痕还会考虑累计长度。

### C 区

C 区规则允许一定尺寸范围内的 `splash`，但超出尺寸阈值会影响合格性。`scratch` 仍需按尺寸规则判断。

### D 区

D 区接近边缘。当前代码中 D 区主要对 `chipping` 做不合格判断，阈值约为 `100 um`。D 区中的 `splash` 和 `scratch` 通常被标记为忽略。

### OUT 区

OUT 区不参与最终合格性判定。OUT 区缺陷通常说明检测框落在样品圆外或圆形拟合边界之外。

## 4. CSV 字段解读

缺陷明细文件 `defect_detail.csv` 是解释结果的主要依据。

关键字段：

- `category`：缺陷类型。
- `confidence`：模型置信度。
- `region`：区域 A/B/C/D/OUT。
- `width_px`、`height_px`、`max_size_px`：缺陷框尺寸。
- `region_ratio`：相对圆心距离比例。
- `is_qualified`：该缺陷按规则是否合格。
- `is_ignored`：该缺陷是否被规则忽略。
- `reason`：不合格或忽略原因。
- `weber_contrast`、`cnr`、`dsnr`：对比度指标。
- `contrast_level`：对比度等级。

区域统计文件 `defect_summary.csv` 用于快速查看每个样品、表面和区域的缺陷数量。

## 5. 回答缺陷问题时的要求

当操作员询问“这个缺陷严重吗”时，应优先读取最新 `defect_detail.csv` 和 `defect_summary.csv`，并回答：

1. 缺陷类型。
2. 缺陷位置，包括样品编号、表面和区域。
3. 是否影响合格性。
4. 触发规则或忽略原因。
5. 关键尺寸、置信度和对比度指标。
6. 建议复核动作。

如果缺陷被标记为 `is_ignored=True`，应明确说明它当前不参与不合格判定，但仍可建议检查原图和融合图确认是否为真实缺陷。

## 6. 复核建议

以下情况建议人工复核：

- 同一位置连续多次出现不合格。
- `confidence` 较低但尺寸接近阈值。
- `contrast_level` 很低但模型仍输出检测框。
- OUT 区缺陷数量异常增多。
- D 区出现大量被忽略缺陷。
- 融合图边缘明显错位。

人工复核应同时查看检测图、融合图、三相机原图和 CSV 明细。
