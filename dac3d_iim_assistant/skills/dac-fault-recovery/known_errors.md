# Known Error Classes

- `path_missing`: offline image folder does not exist.
- `path_not_allowed`: folder is outside the approved workspace.
- `schema_invalid`: generated command does not match registered schema.
- `runtime_busy`: DAC runtime is already running or initializing.
- `bridge_unavailable`: status or command bridge file cannot be read/written.
- `result_missing`: no latest result has been published.
