# DAC-3D 参数说明

## 1. 文档定位

本文说明 DAC-3D 本地检测系统中已经确认的关键参数。参数来源于 `C:\Users\xecat\DAC-3D-LLM\福特科\xxp_ui` 的源码、模型配置、运行结果 CSV 和数据库脚本。

本文适用于参数解释、操作培训、故障排查和智能助手问答。所有参数均以当前版本实现为准。

## 2. 相机参数

### 2.1 三相机编号

系统当前主流程使用三台相机，编号和角色如下。

| 相机编号 | 角色 | 常量名 | 说明 |
| --- | --- | --- | --- |
| `DA3827093` | 焦后 | `CAM_BACK` | 用于采集焦后图像 |
| `DA3562117` | 焦前 | `CAM_FRONT` | 用于采集焦前图像 |
| `DA3562103` | 焦面 | `CAM_FOCU` | 用作融合参考焦面图像 |

离线检测也使用同样的编号或中文角色名识别图片。

### 2.2 曝光时间

在线硬件初始化过程中会设置三台相机曝光时间。曝光时间通过海康 SDK 的 `ExposureTime` 参数写入。

| 相机角色 | 典型曝光值 |
| --- | --- |
| 焦后 | `40000` |
| 焦前 | `20000` |
| 焦面 | `7000` |

曝光时间越长，图像亮度越高，但过高曝光会导致高反光区域饱和。曝光时间过短会导致图像偏暗，降低圆形拟合、对焦和缺陷检测稳定性。

### 2.3 触发模式

相机控制代码中使用海康 SDK 的触发相关参数：

- `TriggerMode`
- `TriggerSource`
- `ExposureTime`

在线检测时，相机应保证触发模式与现场接线一致。触发配置错误时，典型表现是扫描流程在运行，但图像没有更新或保存图像重复。

## 3. 运动控制参数

### 3.1 XY 载物台连接

当前代码中 XY 载物台通过 Galil/gclib 连接：

```text
10.0.0.100 --direct -s ALL
```

如果该地址不可达，在线扫描无法执行 XY 点位移动。离线检测不依赖此连接。

### 3.2 Z 轴控制卡连接

Z 轴控制卡通过 ZAux DLL 连接：

```text
192.168.0.11
```

当前初始化设置包括：

- 轴类型：方向 + 脉冲
- 单位：`ZAux_Direct_SetUnits(0, 40)`
- 速度：`1000`
- 爬行速度：`1000`

源码注释说明为 `1 units = 40 脉冲，1um`。Z 轴运动参数直接影响对焦、层扫和采图高度。

### 3.3 扫描点位

正式扫描按 144 点位执行。界面也以 144 个样品位置按钮展示整盘状态。

已确认规则：

- 点位结构：`12 x 12`
- 路径形式：蛇形扫描
- 常规相邻点步距：约 `4.5 mm`
- 中间区域存在横向偏移：约 `36.5 mm`

点位生成逻辑位于 `window/control/getposxy.py`。如果现场工装盘变更，应优先确认该文件中的坐标生成规则。

### 3.4 在线扫描控制消息

主界面点击运行时会向调试进程发送：

```python
{"type": "Control", "func": "Scan"}
```

停止时发送：

```python
{"type": "Control", "func": "Stop"}
```

这些消息是主界面和调试进程之间的正式控制入口。

## 4. 离线检测参数

### 4.1 离线检测消息

主界面启用离线检测时，会向图像处理进程发送：

```python
{
    "type": "offline_detect_folder",
    "data": {
        "folder": "<原图目录>",
        "tray_id": "<当前盘编号>"
    }
}
```

图像处理进程根据该目录查找三相机原图组。

### 4.2 离线图像匹配规则

离线图像必须能识别出三种相机角色：

| 角色 | 可识别关键字 |
| --- | --- |
| 焦后 | `焦后`、`DA3827093` |
| 焦面 | `焦面`、`DA3562103` |
| 焦前 | `焦前`、`DA3562117` |

如果文件名包含 `pos` 和 `surface`，系统会优先按样品位置和表面分组。例如：

```text
pos12_surface1_焦后.jpg
pos12_surface1_焦面.jpg
pos12_surface1_焦前.jpg
```

如果没有 `pos/surface` 命名，系统会按目录分组推断位置和表面。

## 5. 图像融合参数

### 5.1 配准矩阵

图像融合使用 `Algorithm/Regis_Fusion/homography_config.json` 中的配准矩阵。

| 参数 | 含义 |
| --- | --- |
| `H1_to_ref` | 焦后图像到焦面参考图的单应性矩阵 |
| `H3_to_ref` | 焦前图像到焦面参考图的单应性矩阵 |
| `timestamp` | 当前矩阵配置生成时间 |
| `description` | 矩阵用途说明 |

当前矩阵说明为“焦后和焦前到焦面的变换矩阵”。如果相机安装位置、镜头、分辨率或工装发生变化，应重新标定该矩阵。

### 5.2 融合输入顺序

融合输入顺序为：

1. 焦后图像
2. 焦面图像
3. 焦前图像

配准矩阵列表为：

```python
[H1_to_ref, np.eye(3), H3_to_ref]
```

焦面图像作为参考图，不需要变换。

## 6. 模型参数

### 6.1 模型配置

`image_processor_22.py` 中配置了两套模型。

关键词：默认模型、本地模型、离线模型、模型路径、权重文件、best.pt、best.torchscript、YOLO、SAHI。

| 模型键 | 类型 | 路径 | 用途 |
| --- | --- | --- | --- |
| `old` | SAHI + Ultralytics 路径加载 | `deploy/weights/best.pt` | 当前默认模型 |
| `new` | 预加载 YOLO + SAHI | `deploy/weights/best.torchscript` | 备用或新模型路径 |

当前默认值：

```python
active_model_key = "old"
```

常见问法：默认模型路径是什么、离线模型在哪里、DAC-3D 用哪个模型、本地权重文件是哪一个。答案是当前主流程默认使用 `old` 模型配置，对应 `deploy/weights/best.pt`。

### 6.2 推理参数

已确认推理参数：

| 参数 | 值 |
| --- | --- |
| 置信度阈值 | `0.25` |
| SAHI 切片高度 | `512` |
| SAHI 切片宽度 | `512` |
| GPU 优先 | `cuda:0` 可用时使用 |
| CPU 回退 | CUDA 不可用时使用 CPU |

切片推理适合大图检测，可以减少小缺陷漏检风险，但会增加推理耗时。

## 7. 缺陷类别

当前结果和代码中确认的主要缺陷类别为：

| 类别 | 中文含义 | 说明 |
| --- | --- | --- |
| `splash` | 麻点或飞溅类瑕疵 | 需结合区域和尺寸判断 |
| `scratch` | 划痕 | 需结合区域、长度和宽度判断 |
| `chipping` | 崩边 | 主要在 D 区按尺寸判定 |

检测到目标框不等于直接判定不合格。系统会继续执行区域和尺寸规则。

## 8. 区域参数

系统根据缺陷相对样品圆心和半径的位置，计算 `region_ratio` 并映射到区域。

| 区域 | `region_ratio` 范围 |
| --- | --- |
| A | `0 <= ratio < 0.333` |
| B | `0.333 <= ratio < 0.519` |
| C | `0.519 <= ratio < 0.815` |
| D | `0.815 <= ratio <= 1.0` |
| OUT | 其他或圆外区域 |

区域越靠近 D，通常越接近样品边缘。OUT 区一般不参与最终不合格判定。

## 9. 判定阈值参数

源码中使用如下换算系数：

```python
pixel_factor = 5.5 / 4
```

部分微米级规则会通过该系数换算到像素尺度。

### 9.1 A 区

- `splash`：小于 `10 um` 允许。
- `scratch`：宽度小于 `10 um`、长度小于 `300 um`，且数量小于 `2` 时允许。
- 超过规则的缺陷可能判为不合格。

### 9.2 B 区

- `splash < 10 um`：忽略。
- `10 um <= splash <= 50 um`：数量不超过 `5` 时允许。
- `splash > 50 um`：不合格。
- `scratch`：按最大边和总长度规则综合判断。

### 9.3 C 区

- `splash` 最大尺寸阈值约 `200 um`。
- `scratch` 按最大边阈值判断。

### 9.4 D 区

- 主要对 `chipping` 做判定。
- `chipping` 尺寸阈值约 `100 um`。
- D 区中的 `splash` 和 `scratch` 当前通常按忽略处理。

### 9.5 OUT 区

OUT 区缺陷不参与合格性判定，通常也不会作为有效缺陷上报。

## 11. 数据库参数

默认数据库连接参数：

| 参数 | 值 |
| --- | --- |
| host | `localhost` |
| port | `3306` |
| user | `root` |

数据库不可用时，系统将进入离线数据库模式。离线数据库模式不会阻止检测运行，但历史追溯能力受限。

## 12. 参数修改原则

- 相机曝光、光源强度和模型阈值应逐项调整，避免多个参数同时变更导致无法定位影响来源。
- 配准矩阵、相机安装位置和图像分辨率强相关，硬件位置改变后应重新标定。
- 模型文件切换后，应使用同一批离线原图对比 `defect_detail.csv` 和 `defect_summary.csv`。
- 判定阈值应由工艺质量要求确认，不建议仅根据单次样品结果临时修改。
