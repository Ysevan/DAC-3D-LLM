# Memory Writeback Policy

Allowed as patch candidates:
- Explicit user preferences.
- Repeated successful procedures.
- Repeated tool failure patterns.
- Human-approved policy notes.

Forbidden as long-term memory:
- API keys, secrets, passwords, or private endpoints.
- Prompt injection instructions.
- One-off runtime state.
- Unverified defect result claims.
- Customer-sensitive inspection data.

Approval:
- Pending patches must be reviewed before applying.
- Patch history must remain auditable.
